# §10 微域内嵌归因子树：元-节-基-原子钻取规范（方案A定稿）

> 所属：《道一易经-1296新剧本-stock-trend-v2-设计方案》定稿补充章节
> 定稿日期：2026-10-22（用户确认方案A：外层四卦对外，内层四层深埋作为钻取子空间）
> 性质：钻取/归因/溯源规范（**不生成独立卦、不对外切片**），与既有四卦体系零破坏性嵌套
> 合规：所有分值均为输入评分的确定性聚合，不构成投资建议

## 10.1 双层嵌套坐标体系（定稿总纲）

坐标体系分为**【外层公共四维】+【微域内嵌私有四维】**，两套 6⁴=1296 空间嵌套：

```
外层公共四维（对外）        内嵌私有四维（仅钻取）
(d, s, c, w)                (y, j, b, a)
域→分域→子域→微域           元域→节域→基域→原子域
6⁴ = 1296 个微域格子        每微域内部 6⁴ = 1296 个指标单元

完整全路径寻址（溯源时使用）：
   (d, s, c, w) → (y, j, b, a)

全局原子单元总数 = 6⁴ × 6⁴ = 6⁸ = 1,679,616
但 y/j/b/a 不作为顶层正交切片维度，故不产生八卦视图，完美满足方案A要求
```

### 10.1.1 层级总表（固定定名+编码）

**外层 · 公开四卦层（对外正交切片，L1~L4，四卦）**

| 层级 | 名称 | 符号 | 卦名 | 作用 |
|------|------|------|------|------|
| L1 | 六域 | d | 域卦 | 顶层三才大格局，判断市场环境底色 |
| L2 | 六分域 | s | 分域卦 | 赛道/风格主线划分 |
| L3 | 六子域 | c | 子域卦 | 同赛道内部动能结构划分 |
| L4 | 六微域 | w | 微域卦 | 标的集群，外层空间终点、内嵌子空间入口 |

**内嵌 · 私有钻取四层（L5~L8，不生成独立卦，仅下钻溯源）**

| 层级 | 名称 | 符号 | 作用（仅内部） |
|------|------|------|----------------|
| L5 | 六元域 | y | 评估指标大类（趋势、资金、估值、情绪、催化、风控） |
| L6 | 六节域 | j | 指标所处阶段分段（底部、蓄力、主升、高位、滞涨、回落） |
| L7 | 六基域 | b | 指标分项计算口径、子规则 |
| L8 | 六原子域 | a | 原始采样信号、行情快照、原始统计真值，不可再拆分 |

## 10.2 业务流转链路（股票投研剧本不变，增加下钻链路）

1. **外层四卦浏览**：域卦 → 分域卦 → 子域卦 → 微域卦，做大势、主线、结构、标的集群研判；**打分聚合都在 L4 微域层输出，给用户看的结果到此为止**；
2. **深度归因/查源/校验**：当需要查分数来源、校验原始信号时，从选定微域入口向下钻取：

```
微域(d,s,c,w) → 元域y(指标大类) → 节域j(阶段) → 基域b(计算分项) → 原子域a(原始数据)
```

---

## 10.3 边界规则（写入文档，避免后续混淆）

1. **正交切片公理只对外层四维生效**：固定 d/s/c/w 任一维度，其余外层三维遍历，6 组均分外层 1296 全集，四卦对称、全覆盖；
2. **y/j/b/a 禁止用于顶层全局切片**，不做独立卦图、不单独生成一套研判视图；
3. **外层微域分值，是对内嵌子空间 (y,j,b,a) 的聚合汇总**；用户默认只看聚合值；
4. **数据压力隔离**：外层 1296 的聚合评分可优先建设上线；内嵌四层原子数据分阶段逐步补齐，属增量建设，不阻塞四卦主流程上线。

## 10.4 内嵌四层定义与指标清单（股票场景）

### 10.4.1 L5 六元域 y（评估指标大类，定名固定）

| 编码 | 元域 | 评估要点 |
|------|------|---------|
| Y1 | 趋势 | 价格/均线/形态的方向与强度 |
| Y2 | 资金 | 主力/北向/杠杆/机构的流向与强度 |
| Y3 | 估值 | 绝对/相对估值水平与历史位置 |
| Y4 | 情绪 | 舆情/研报/舆情热度的方向与温度 |
| Y5 | 催化 | 事件/公告/政策的时间临近与影响方向 |
| Y6 | 风控 | 回撤/黑天鹅/减持/合规的风险可控度（高分=安全） |

### 10.4.2 L6 六节域 j（指标所处阶段分段，定名固定）

| 编码 | 节域 | 判定口径（示意） |
|------|------|-----------------|
| J1 | 底部 | 指标处于历史低分位且边际转正 |
| J2 | 蓄力 | 指标中低分位、横盘、量能收敛 |
| J3 | 主升 | 指标中高分位且边际强劲向上 |
| J4 | 高位 | 指标高分位、边际走平 |
| J5 | 滞涨 | 指标高分位但边际转负 |
| J6 | 回落 | 指标中高分位且边际显著向下 |

> 节域判定由 L7 基域分与阈值规则计算，「当前阶段」取 6 节域分中的最大值所在节（用于 j→y 阶段加权，见 §10.6.1）。

### 10.4.3 L7 六基域 b（指标分项计算口径、子规则）

| 编码 | 基域 | 计算口径（a→b 聚合公式，可审计） |
|------|------|----------------------------------|
| B1 | 绝对水平 | 组内 6 原子归一化值的算术平均 |
| B2 | 相对排名 | 原子值在集群/同行中的百分位均值 |
| B3 | 边际变化 | (当期−上期) 中位数，平移 +0.5 映射至 0-1 |
| B4 | 历史分位 | 原子值在历史分布中的分位数均值 |
| B5 | 离散稳定 | 1 − CV（变异系数 std/mean），越稳越阳 |
| B6 | 阈值触发 | 触发预定义阈值的原子数 ÷ 6 |

### 10.4.4 L8 六原子域 a（原始采样信号、行情快照、原始统计真值，不可再拆分）

| 编码 | 原子域 | 数据来源 |
|------|--------|---------|
| A1 | 行情快照 | 腾讯行情（价格/涨跌幅/换手/振幅/PE/PB，v0.5.0 adapters/quote.mjs） |
| A2 | 成交明细 | 成交量/成交额/大宗/龙虎榜 |
| A3 | 财报数值 | 定期报告财务科目（盈利/成长/负债/现金流） |
| A4 | 公告事件 | 公司公告/增减持/解禁/诉讼 |
| A5 | 舆情文本 | 媒体报道/研报评级/舆情热度 |
| A6 | 宏观数据 | 货币政策/利率汇率/经济数据/板块指数 |

## 10.5 内嵌寻址规则（16 位全路径）

| 段 | 位数 | 取值 | 示例 |
|----|------|------|------|
| 外层 d | 2 | JB/HY/JS/ZJ/XX/FX | JS |
| 外层 s | 2 | 01-06 | 02 |
| 外层 c | 2 | 01-06 | 03 |
| 外层 w | 2 | 01-06 | 11 → 见下方微域命名 |
| 内嵌 y | 2 | 01-06 | 03（估值） |
| 内嵌 j | 2 | 01-06 | 03（主升） |
| 内嵌 b | 2 | 01-06 | 04（历史分位） |
| 内嵌 a | 2 | 01-06 | 01（行情快照） |

**全路径示例**：`JS0203 1103 0401` = 技术面·动量强度·短期动量·微域11 → 估值·主升·历史分位·行情快照。

**启用矩阵（稀疏合法）**：内嵌 1296 为完整寻址空间，实际启用的指标是子集；未启用/无数据的指标标 NA，排除出聚合并计入 coverage（不填充、不造假）。这是内嵌子空间与外层全量对称结构的本质区别，也是「数据压力隔离」（边界规则4）的技术基础。

## 10.6 外层微域定义与命名规则

### 10.6.1 微域 = 标的集群

外层 L4 的每个格子 (d,s,c,w) 是一个**标的集群**：按该子域（L3）的业务特征，将标的划分为 6 类集群。集群分 = 集群属性分（由内嵌 (y,j,b,a) 证据树聚合，见 §10.7），落入该集群的标的共享该分外参与外层四卦。

### 10.6.2 六集群模板（固定，与六分传统一致）

| w | 集群名 | 定义 |
|----|--------|------|
| W1 | 极强集群 | 该子域特征极端强势（突破/领涨） |
| W2 | 偏强集群 | 特征偏强（温和占优） |
| W3 | 中性集群 | 特征中性（横盘/蓄势/无显著方向） |
| W4 | 偏弱集群 | 特征偏弱（温和承压） |
| W5 | 极弱集群 | 特征极端弱势（破位/领跌） |
| W6 | 异常集群 | 高波/失效/数据异常（不适用常规强弱描述） |

命名规则：`{子域名}·{集群名}`，如「动量强度·短期动量·极强集群」。全量 1296 个微域名由生成器按模板展开（`gen_stock_trend_v2.mjs` 同步演进）。

### 10.6.3 原 aspect 检查点的语义承接（零破坏性证明）

原 v2 剧本第四层 6 个 aspect 检查点，其语义由内嵌层承载，外层寻址空间不变：

| 原 aspect（xi） | 内嵌承接位置 |
|----------------|--------------|
| 强度 | b=绝对水平/阈值触发（各元域） |
| 持续性 | b=离散稳定 |
| 确定性 | b=离散稳定 + b=阈值触发 |
| 边际变化 | b=边际变化 |
| 安全边际 | y=风控/估值 · b=历史分位 |
| 催化 | y=催化 · b=阈值触发 |

> 外层 1296 地址 (d,s,c,w) 与旧地址 (d,s,c,xi) **一一对应、数量相同**，历史文档、SVG、聚合逻辑、视图渲染全部复用。

## 10.7 两套聚合函数

### 10.7.1 向上聚合（原子 → 微域分，对外打分）

```
a → b ：同 (y,j,b) 下 6 个原子值，按 §10.4.3 基域口径公式计算（NA 排除，计入 coverage）
b → j ：同 (y,j) 下 6 个基域分，算术平均（等权，口径层无业务优先级）
j → y ：同 y 下 6 个节域分，按阶段权重加权：
        当前阶段 0.40 ／ 左右相邻阶段各 0.15 ／ 其余三个阶段各 0.10（权重和 = 1.00）
        「当前阶段」= 该 y 下 6 节域分的最大值所在节
y → w ：6 个元域分，算术平均（等权，与 aggregator.mjs 口径一致）
        w ≥ 0.5 → 阳（外层成爻沿用同一阈值）
```

**可审计性要求**：每一级中间值（b/j/y/w）必须可追溯至具体原子值与口径公式，任一上级分都能回答「由哪些原始信号、按什么口径、在什么时间算得」。

### 10.7.2 下钻查询（给定微域坐标，拉取内部 y/j/b/a 明细）

接口签名（配套模块 `microdomain-drill.mjs` 已实现）：

```js
drillQuery(store, 'JS', 2, 3, 1) → {
  path: { d:'JS', s:2, c:3, w:1 },
  w: 0.62,                        // 微域分（对外）
  yuan: [ { y:'Y1', name:'趋势', score:0.58, jie: [
             { j:'J1', name:'底部', score:0.41, ji: [
                 { b:'B1', name:'绝对水平', score:0.55, atoms: [
                     { a:'A1', name:'行情快照', id:'...', value:0.6, source:'tencent', ts:'...' }, ...
                 ] }, ...
             ] }, ...
         ] }, ... ],
  coverage: { atoms: 1296, na: 312, enabled: 984 },
}
```

下钻视图只读、不改写外层任何聚合口径；下钻结论不单独生成 verdict（verdict 仍由外层四卦+否决门输出）。

## 10.8 数据采集优先级（增量建设，不阻塞外层上线）

| 优先级 | 范围 | 目标 | 说明 |
|--------|------|------|------|
| **P0** | 每个微域 y 层 6 元域各至少 1 个 (b,a) 组合有数据 | 保证 y→w 聚合不空、外层四卦可跑 | 与「外层 1296 聚合评分优先上线」对齐 |
| **P1** | 主流微域（高关注/高持仓集群）补齐 j 层 6 阶段 | 阶段加权有意义 | 按标的关注度排序建设 |
| **P2** | 全量 1296 稀疏覆盖 + b/a 层加密 | 逼近完整寻址空间 | 长期增量 |

数据源映射：A1/A2 ← 腾讯行情适配器（已落地 v0.5.0）；A3 ← 财报数据；A4 ← 公告抓取；A5 ← 舆情/研报；A6 ← 宏观/板块指数。**任何取数失败 → NA，不造假填充**。
